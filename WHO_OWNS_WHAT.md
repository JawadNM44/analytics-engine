## Safety rules

- No Terraform Apply from any AI assistant without Jawad's approval.
- No always-on Cloud Run service without explicit cost approval.
- No real-money trading, order placement, wallet access, or exchange API keys in early phases. Paper trading only until a separate safety review exists.
- No LLM/API keys in repo or direct Cloud Run env vars. Use Secret Manager.
- Keep `crypto-api` private. Browser traffic must continue to go through the public Next.js dashboard.
- If a feature needs IAM grants and immediately depends on them, include a propagation wait (`time_sleep`) — see `CHANGELOG.md` incidents for the pattern.
- If one assistant thinks another's draft is wrong, open an issue or comment on the PR. Do not silently rewrite.
